## 🧭 About Me

<img align="right" src="https://raw.githubusercontent.com/kirillmarkin/kirillmarkin/main/assets/cloud_computing.gif" width="260"/>

- 📊 I build observability stacks with **CloudWatch, Prometheus, and Grafana** to keep systems reliable.

## 🔐 DevSecOps

Security is embedded across every stage of the pipeline, not bolted on afterward:

| Practice | Purpose |
|---|---|
| **SAST** | Static analysis of source code to catch vulnerabilities early |
| **DAST** | Dynamic testing of running applications for runtime security flaws |
| **SCA** | Scanning dependencies for known vulnerabilities |
| **IaC Security** | Validating Terraform/Ansible configurations against security best practices |
| **Container Security** | Hardening and scanning Docker images |
| **Cloud Security** | Enforcing least-privilege IAM, network, and resource policies |
| **SonarQube** | Continuous code quality and security analysis |
